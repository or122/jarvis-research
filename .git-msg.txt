Shared rooms with paid seats - Or's original idea for Flow

Several people on the same wifi talk to Flow together. The free tier gives 2
seats; the third person is blocked until the room is upgraded. That refusal is
the business model, so it is tested first and it actually works.

The server owns the conversation, not the browsers. Every message becomes a
row with a sequence number the server assigns, and clients ask "what happened
after number N?". Two people typing at the same instant is therefore safe -
whoever's row lands first is first, and everyone sees one order. The obvious
alternative, each browser keeping its own list, disagrees the moment two
people type.

- rooms.py: SQLite rooms/members/messages, 5-letter join codes without
  ambiguous characters, seat limits, and a recent_context() capped at 4 turns
  because the model's whole memory is 128 tokens
- server.py: /rooms, /rooms/join, /rooms/<id>/say, /rooms/<id>/paid and a
  polling GET. A full room returns HTTP 402 Payment Required, which is
  literally what the situation is.
  Flow answers on a background thread after a 1.5s pause, so two people
  talking together get ONE reply that has read both rather than two replies
  talking over each other. If someone posts during the pause, that thread
  stands down.
  FLOW_HOST controls binding: 127.0.0.1 stays the default, 0.0.0.0 opens it to
  the local network for rooms and prints a warning, since anyone on that wifi
  can then reach it.
- Rooms.tsx: lobby to create or join, live message list by polling every 1.5s,
  seat counter, and the upgrade path when a room is full
- App.tsx: server address is now location.hostname, not localhost - another
  device on the wifi must reach this Mac, and localhost would point at itself

Verified end to end through the running server:
  Or creates a room            -> code 7TJ3J
  Ariel joins                  -> members [Or, Ariel]
  Eden joins                   -> HTTP 402 {"error":"full","seats":2}
  Or and Ariel both speak      -> Flow replies once: "144" to "what is 12 times 12"
